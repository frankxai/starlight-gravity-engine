# Markdown Starter

The Gravity Engine with **zero install** — just files and any capable AI agent.
This is the fifteen-minute on-ramp. You can graduate to the Local Engine later
without losing anything.

## What's here

```
markdown/
  DIRECTION.md              Your gravity well — fill this in first
  FIELD-NOTE.template.md    A blank encounter note — copy it per encounter
  field-notes/              One markdown file per encounter
    2026-07-22-example.md   A worked example note
  prompts/
    gravity-capture.md      Paste after an encounter → five suggestions
    gravity-review.md       Paste weekly → gravity reading + weakest force
```

## Fifteen minutes

1. Copy this folder anywhere (or into your notes vault).
2. Open `DIRECTION.md` and fill in your statement, horizon, themes, and values.
3. After your next real encounter, add a note under `field-notes/`.
4. Open the folder with any capable AI agent and paste `prompts/gravity-capture.md`
   together with your note.
5. You'll get five outputs — strongest signal, artifact opportunity,
   follow-through, appreciation/introduction, room theme — each yours to approve
   or decline.
6. Seven days later, paste `prompts/gravity-review.md`.

## The rules the agent must follow

These are non-negotiable and are written into the prompts:

- Observable only — never speculate about attraction, diagnosis, hidden intent,
  or someone's worth.
- No rankings of people, ever.
- Nothing is published or sent. Every output is a suggestion you approve.
- Private by default.

When you're ready for a deterministic, durable version of exactly this loop, see
the [Local Engine quick start](../../QUICKSTART.md).
